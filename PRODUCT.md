# Product

## Users

The owner, and every coding agent working in the owner's projects.

## Purpose

One standard (git, commits, versions, releases, layout, local-only demos)
that every project follows without the owner restating it. The owner runs
`jb install` once per machine; agents do everything else.

## Not

Not a framework or UI kit: stack and design are chosen per project. Not a
command the owner is expected to learn.

## Platform

macOS and Linux, bash, git, jq; Claude Code for hooks and skills.
